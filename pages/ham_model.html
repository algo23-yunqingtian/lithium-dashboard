模型框架：Brock-Hommes 异质 Agent 模型，观测模式（外部输入真实价格，不闭环出清）

主体1：产业基本面 Agent
对应现实角色：锂矿资源商、冶炼厂、贸易商、正极厂
需求函数：D_f(t) = α × (P_fund(t) − P(t))
行为逻辑：价格高于公允价→做空；低于公允价→做多
参数 α = 0.3（基本面回归强度）

主体2：投机趋势 Agent
对应现实角色：CTA 趋势资金、游资、散户
需求函数：D_c(t) = β × (P(t) − P(t−1))
行为逻辑：基于价格动量追涨杀跌
参数 β = 0.5（趋势外推强度）

策略切换（HAM 核心）
滚动收益：Profit_f(t) = Σ D_f(i) × (P(i+1) − P(i))，窗口 W=20
群体权重：n_f = exp(γ×Profit_f) / (exp(γ×Profit_f) + exp(γ×Profit_c))
参数 γ = 2（策略切换灵敏度）

输出因子
Total_Demand = n_f × D_f + n_c × D_c（聚合需求）
n_f − n_c（力量分歧）

合格标准：RankIC 稳定正/负，ICIR 绝对值 > 0.3，分层回测单调

模型边界
✅ 识别投机力量占比变化、市场博弈结构
❌ 不预测每日价格涨跌点位
⚠️ 禁止单独用因子做买卖信号，应作为 ML 模型输入特征
